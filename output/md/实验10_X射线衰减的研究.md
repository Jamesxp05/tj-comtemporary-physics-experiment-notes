# 实验 10　X 射线衰减的研究

## 10.1　引言

1895 年，德国科学家伦琴（W. K. Rontgen）发现 X 光，是人类揭开研究微观世界序幕的“三大发现”之一（另外两大发现分别是 1896 年法国贝克勒尔发现放射性和 1897 年英国汤姆逊发现电子），X 光管的制成，则被誉为人造光源史上的第二次大革命（第一次是电灯的制成，第三次是激光的出现）。X 光也叫 X 射线，它是波长在 0.001 nm 到 100 nm 范围的电磁波，它在医学（如 X 射线诊断）、工业（如 X 射线探伤）、材料科学（如 X 射线分析）、天文学（如 X 射线望远镜）、生物学（如 X 光显微镜）等方面的应用十分广泛。100 多年来，它对人类的贡献是巨大的。所以，X 射线的性质、应用及与此相关研究领域也逐渐形成了十分丰富的研究体系。

## 10.2　实验目的

（1）了解 X 射线的产生机制、特点和应用。

（2）研究 X 射线的衰减与吸收体的厚度关系。

（3）研究 X 射线的衰减系数与波长及吸收体材料的关系。

## 10.3　实验原理

### 10.3.1　X 射线谱

X 射线谱一般采用高速电子轰击靶核的方法产生。图 10-1 为 X 射线管的构造。管内旁热式加热的阴极发射的电子在电场作用下打在阳极靶核上，产生 X 射线。调节此电压可以改变轰击阳极电子的能量。

**图 10-1　X 射线管**：示意 X 射线管的结构。玻璃管（内含高真空）两端分别为灯丝（−）和金属靶（+）；高压使电子从灯丝飞向金属靶，靶处产生并射出 X 射线。图中标有“高压”“金属靶（+）”“电子”“灯丝（−）”和“X 射线”。[查看原 PDF 第 114 页](../../近代物理实验教材.pdf#page=114)

X 射线谱包括两个部分：波长连续变化的连续谱和具有分立波长的标识谱。连续谱由轫致辐射产生：经典电动力学告诉我们，带电粒子在加速或减速时伴随辐射，当电子与靶核相碰撞时，一部分动能转化为辐射能，一部分动能转化成热能使靶变热。电子的速度是连续变化的，因此辐射的 X 射线具有连续谱的性质。它的最小波长只与外加电压有关，强度正比于靶核电荷的平方，反比于入射带电粒子质量的平方。分立波长的标识谱取决于靶材料本身，是由电子内壳层的跃迁产生的。峰值的位置与外加电压无关。

### 10.3.2　X 射线的衰减

光子与物质相互作用主要包括：光电效应——光子与束缚电子的相互作用；康普顿散射——光子与自由电子的散射；电子偶效应——光子的能量大于电子静止能量的两倍，光子在原子核附近转化为一对正负电子。

所谓 X 射线的衰减，指的是辐射穿过物质时发生的强度的减弱。X 射线由低能光子组成，X 射线穿过介质时发生的相互作用主要是光电效应和康普顿散射。X 射线量子在衰减体材料原子上的散射会引起部分辐射改变方向，这减小了在原来方向上的强度。这个散射可以是弹性散射或非弹性散射，即有能量损失或者波长偏移的散射。在吸收时，X 射线量子的全部能量被转移给被辐照材料的原子或者分子作为激发能或电离能。对一定波长的 X 射线，原子序数 Z 大的重元素比 Z 小的轻元素吸收作用大，其吸收量与 Z⁴ 成正比。

**图 10-2　X 射线经过衰减物质**：示意入射强度为 I₀ 的 X 射线通过厚度 x 的衰减物质后，强度减为 I=I₀e^(−μx)。[查看原 PDF 第 115 页](../../近代物理实验教材.pdf#page=115)

如果 I₀ 是不经过衰减体时的计数率，而 I 是经过衰减体后的计数率，则可以利用 I/I₀ 来量化辐射的透射，以表征一个衰减体的透射率。衰减体的透射率越大，其衰减能力越低。

$$T=\frac{I}{I_0}\tag{10-1}$$

透射依赖于衰减体的厚度。假定入射辐射的性质不变，则厚度 x 增加 dx，透射率 T 就减少 dT。因此，透射率的相对减小与厚度的绝对增加成正比

$$-\frac{dT}{T}=\mu\,dx\tag{10-2}$$

比例因子 μ 称为线性衰减系数。

在 x=0 时，T=1，对式（10-2）积分得

$$T=e^{-\mu x}\tag{10-3}$$

或

$$\ln T=-\mu x\tag{10-4}$$

这个关系式叫做衰减的朗伯定律，以 18 世纪数学家和物理学家约翰·海因里希·朗伯（J. H. Lambert）的名字命名。

（二维码图注：X 射线的判断方法）

利用物质对 X 光的吸收作用，我们可以对吸收体（材料或者生物体）进行无损检测（也叫探伤、透视）。这种方法主要是根据 X 射线经过衰减系数不同的吸收体时，所穿过射线强度不同而实现的。若被检验的物质中存在着气泡、裂纹、夹杂物或生物体中的病变等，由于这些部位对 X 射线吸收各不相同，因此在透射方向的感光底片上便出现深浅不一的阴影。根据阴影可以判断物质内部缺陷的部位和性质。一般来说，缺陷的厚度仅为吸收体厚度的 1% 时，就可以被检验出来。

## 10.4　实验仪器

X 射线实验仪如图 10-3 所示，其正面装有两扇铅玻璃门，既可看清楚 X 射线管和实验装置的工作状况，又保证了人身不受到 X 射线的危害。为保护操作者的安全，一旦打开玻璃门，X 射线管上的高压会立即断开。该装置分为三个工作区：中间是 X 射线管，右边是实验区，左边是监控区。

**图 10-3　X 射线实验仪**：仪器分为左侧监控区、中部 X 射线管和右侧实验区。监控区示出液晶显示区 B1、大转盘 B2、设置按键 B3、扫描模式按键 B4 和操作按键 B5；实验区示出准直器 A1、样品靶台 A2、GM 计数管传感器 A3、荧光屏 A4。图中提示实验区操作须戴手套。[查看原 PDF 第 116 页](../../近代物理实验教材.pdf#page=116)

实验区包括以下装置。

**A1　准直器。** 准直器前后端面各开有一条狭缝，使得从准直器出射的 X 射线形成一束平行的片状光束。准直器前端可套上各种滤波器。

**A2　安放晶体样品的靶台。**

**A3　装有 GM 计数管的传感器，**它用来探测 X 射线的强度。GM 计数管是一种用来测量 X 射线强度的探测器，其计数率与所测 X 射线的强度成正比。由于本实验仪器的 X 射线强度不大，因此计数管的计数率较低，根据放射性的统计规律，射线的强度可表示为 N ± √N，故计数的相对不确定度较大；延长计数管每次测量的持续时间，从而增大总强度计数 N，有利于减少计数的相对不确定度。

A2 和 A3 都可以转动，并可通过测角器分别测出它们的转角。

**A4　荧光屏，**它是一块表面内涂有荧光物质的圆形铅玻璃平板，平时外面有一块盖板遮住，以免环境光太亮而损害荧光物质；让 X 射线打在荧光屏上，打开盖板，即可在荧光屏的右侧外面直接看到 X 射线的荧光，但因荧光较弱，此观察应在较暗的环境中进行。

左边的监控区包括电源和各种控制装置。

**B1　液晶显示区，**分上下两行，上行显示 GM 计数管的计数率 N（正比与 X 射线强度 R），下行显示工作参数。

**B2　大转盘，**用来调节和设置各参数。

**B3　含五个设置按键，**确定 B2 所调节和设置的对象，这五个按键从上至下依次是

（1）U：设置 X 射线管上所加的高压值（通常取 35 kV）；

（2）I：设置 X 射线管内的电流值（通常取 1.00 mA）；

（3）Δt：设置每次测量的持续时间（通常取 5～10 s）；

（4）Δβ：设置自动测量时测角器每次转动的角度，即角步幅（通常取 0.1°）；

（5）β LIMITS：在选定扫描模式后，设置自动测量时测角器的扫描范围，即上限角与下限角。第一次按此键时，显示器上出现“↓”符号，此时利用 B2 选择下限角；第二次按此键时，显示器上出现“↑”符号，此时利用 B2 选择上限角。

**B4　有三个扫描模式选择按键和一个归零按键。** 三个扫描模式按键从左至右依次是：

（1）SENSOR：传感器扫描模式，按下此键时，可利用 B2 手动旋转传感器的角位置，也可用 β LIMITS 设置自动扫描时传感器的上限角和下限角，显示器的下行此时显示传感器的角位置；

（2）TARGET：靶台扫描模式，按下此键时，可利用 B2 手动旋转靶台的位置，也可用 β LIMITS 设置自动扫描时传感器的上限角和下限角，显示器的下行此时显示靶台的角位置；

（3）COUPLED：耦合扫描模式，按下此键时，可利用 B2 手动同时旋转靶台和传感器的角位置——传感器的转角自动保持为靶台转角的 2 倍（图 10-4），而显示器的下行此时显示靶台的角位置，也可用 β LIMITS 设置自动扫描时传感器的上限角和下限角；

（4）ZERO：归零按键，按下此键后，靶台和传感器都回到 0 位，但此 0 位是上次实验时人为确定的。

**图 10-4　COUPLED 模式下靶台和传感器的角位置**：示意入射 X 射线、靶台与传感器的几何关系；靶台转角为 θ，传感器转角为 2θ。[查看原 PDF 第 117 页](../../近代物理实验教材.pdf#page=117)

**B5　有五个操作键，它们依次是：**

（1）RESET：按下此键，靶台和传感器都回到测量系统的 0 位置，所有参数都回到缺省值，X 射线管的高压断开；

（2）REPLAY：按下此键，仪器会把最后的测量数据再次输出至计算机或记录仪上；

（3）SCAN（NO/OFF）：此键是整个测量系统的开关键，按下此键，在 X 射线管上就加了高压，测角器开始自动扫描，所得数据会被储存起来，若开启了计算机的相关程序，则所得数据自动输出至计算机；

（4）[扬声器图标]：此键是声脉冲开关；

（5）HV（ON/OFF）：此键开关 X 射线管上的高压，它上面的指示灯闪烁时，表示已加了高压。

## 10.6　实验内容及步骤

（1）测定 X 射线通过不同厚度的铝 Al 后的强度，计算铝对 X 射线的透射因数及衰减系数。

（2）测量不同材料（原子序数 Z 不同）对 X 射线的透射因数及衰减系数。

### 10.6.1　实验步骤

实验器材中有两个吸收体，如图 10-5 所示。

图 10-5 上：同种物质铝（Al，Z=13），厚度分别为 0.5 mm、1.0 mm、1.5 mm、2.0 mm、2.5 mm、3.0 mm，共六块吸收板。

图 10-5 下：同种厚度（0.5 mm），吸收材料分别为碳（Z=6）、铝（Z=13）、铁（Z=26）、铜（Z=29）、锆（Z=40）和银（Z=47），共六块吸收板。

实验时，按下铅玻璃门下方的黑色按钮，打开铅玻璃门，拆除并取出靶架。关上玻璃移门，按下 SENSOR 键，打开 HV，调节 B2 键使传感器处于计数率最大处。然后，再打开铅玻璃移门，将吸收体的滑槽放进靶支架弯曲的狭缝中。如图 10-6 所示。

**图 10-5　吸收体附件**：上图为放置不同厚度吸收板的卡槽 1a/滑槽 1c，标示不同厚度吸收板 1b；下图为放置不同材料吸收板的卡槽 2a/滑槽 2c，标示不同材料吸收板 2b。每组均示出六个位置。[查看原 PDF 第 118 页](../../近代物理实验教材.pdf#page=118)

**图 10-6　安装吸收板**：示意将吸收板装入靶架狭缝的安装方法。[查看原 PDF 第 118 页](../../近代物理实验教材.pdf#page=118)

（1）测量不同厚度的铝材料的透射因数及衰减系数时，可以不用计算机。实验需要采用两种方式进行：

① 没有锆（Zr）滤波片时设置：U=21 kV，I=0.05 mA，Δt=100 s，Δβ=0；

② 带有锆（Zr）滤波片时设置：U=21 kV，I=0.15 mA，Δt=200 s，Δβ=0。

实验时均采用定时曝光模式。传感器（GM 管）对准从准直器出射的 X 射线后固定不动，通过让靶架每次转动 10° 来更换吸收板。实验步骤是先按 TARGET 键，手动调节 ADJUST 旋钮（B2），让靶架上的样品依次转动一个指定角度（近似 0°、10°、20°、30°、40°、50° 和 60°）。然后，按 SCAN 键开始测量，经过设定的测量时间 Δt 后，按下 REPLAY 键，显示 Δt 内的平均计数率 R，记下此次试验结果。无吸收板（近似 0°）时测得的计数率对应入射 X 光强度为 I₀。

（2）测量厚度相同（0.5 mm），而 Z 不同材料的透射因数及衰减系数时，测量方法与上面一样。实验也要采用两种方式进行：不带锆滤波片与带锆滤波片。

不带锆滤波片时的参数设置：

① 对无吸收体、C、Al 材料（近似 0°、10°、20°）：U=30 kV，I=0.02 mA，Δt=30 s；

② 对 Fe、Cu、Zr、Ag 材料（近似 30°、40°、50°、60°）：U=30 kV，I=1.00 mA，Δt=300 s。

带锆滤波片时的参数设置：

① 对无吸收体、C、Al 材料（近似 0°、10°、20°）：U=30 kV，I=0.02 mA，Δt=30 s；

② 对 Fe、Cu、Zr、Ag 材料（近似 30°、40°、50°、60°）：U=30 kV，I=1.00 mA，Δt=300 s。

实验测得数据应同样列表计算透射因数及衰减系数。

（3）测量本底的影响：设置 U=0 kV，I=0 mA，Δt=300 s，测量本底计数率 R₀。

### 10.6.2　实验数据的记录与处理

## 10.7　实验注意事项

（1）测量孔中有射线发出，不要裸眼观察测量孔，以免辐射损伤。如确需要观察测量孔内部，必须用铅玻璃防护。

（2）在安装吸收板时注意衔接位置，必须佩戴手套正确安装，避免实验中旋转掉落。

（3）在 X 光管开启、测量过程中，不可强行打开玻璃防护门，以免辐射损伤。

（4）实验中注意保护实验器材，减少材料的磨损、消耗，使用完毕需要放置原处。
