# 实验 9　布拉格反射：X 射线在单晶上的衍射

## 9.1　引言

X 射线自 1895 年被发现以来，在理论、设备、方法和应用上都有了迅速发展，并已渗透到了物理、化学、生命科学、地球科学、材料科学以及工程技术各个领域。近几年，由于新 X 射线源和设备的发展，这项技术又得到了兴起。

## 9.2　基础知识

### 9.2.1　晶体

对于晶体，主要对其定义、特性、结构进行介绍。

**1. 晶体定义**

晶体（crystal）是由大量微观物质单位（原子、离子、分子等）按一定规则有序排列的结构。

**2. 晶体特性**

（1）原子排列规则——周期性（长程有序）。  
（2）各向异性：晶体物质在不同方向的排列方式是不同的，因而在不同的方向上，其性质是不相同的。  
（3）晶面角守恒：同一种晶体外形可能不同，但相应的两晶面之间的夹角总是不变的。  
（4）自限性：晶体具有自发的形成封闭几何多面体的特性，这一特性是晶体内部自发原子的规则排列在晶体宏观形态上的反映。  
（5）自由能最小：在热平衡条件下，稳定存在的是自由能最小的物相。

**3. 晶体结构**

**1）晶体的周期结构**

晶体的周期结构是指原子排列的方式。晶体结构的显著特点就是粒子排列的周期性，基元表示晶体中周期性变化的具体内容，它可以是一个原子，也可以是若干相同或不同的原子，取决于具体的晶体结构，点阵代表重复周期的大小和规律，格点是由结构基元抽象出来的几何点。晶体中有如下关系：晶体结构＝点阵＋基元。

如果每个基元中只有一个原子或离子，这样的晶体结构称为简单格子；而如果基元中包含一个以上的原子核离子，则称为复式格子，如 NaCl 为复式格子。

![图 9-1 面心立方结构原胞及基矢（图示晶格原胞、基矢 a₁、a₂、a₃ 及坐标轴）](../../近代物理实验教材.pdf#page=103)

**图 9-1　面心立方结构原胞及基矢**

**2）晶体原胞（固体物理学原胞）**

晶格中某一平行六面体。一个原胞沿三维方向的重复排列构成晶体。原胞的选取有任意性。一个原胞只含一个格点，格点只在顶角上，内部和面上皆不含其他格点。

**3）原胞基矢**

原胞平行六面体从一个顶点出发的三条棱可看成是原胞的三个基矢。

**4）倒格子**

假如晶体点阵的基矢为 \(\mathbf a_1,\mathbf a_2,\mathbf a_3\)，那么存在另一空间，其波矢 \(\mathbf k\) 可看作是量纲为 \(L^{-1}\) 的空间矢量，与波数矢量具有相同的量纲，这样的空间称为倒空间或倒格子空间。

倒格矢 \(\mathbf K_h\) 可表示为 \(\mathbf K_h=h_1\mathbf b_1+h_2\mathbf b_2+h_3\mathbf b_3\)，其中 \(\mathbf b_1,\mathbf b_2,\mathbf b_3\) 满足

\[
\begin{aligned}
\mathbf b_1&=2\pi(\mathbf a_2\times\mathbf a_3)/\Omega,\\
\mathbf b_2&=2\pi(\mathbf a_3\times\mathbf a_1)/\Omega,\\
\mathbf b_3&=2\pi(\mathbf a_1\times\mathbf a_2)/\Omega.
\end{aligned}\tag{9-1}
\]

其中，\(\Omega\) 为正格子原胞体积。

倒格子的性质有：

（1）\(\mathbf a_i\cdot\mathbf b_j=2\pi\delta_{ij}\)；\tag{9-2}

（2）设倒格子原胞体积为 \(\Omega^*\)，则

\[
\Omega^*=\frac{(2\pi)^3}{\Omega};\tag{9-3}
\]

（3）倒格子的倒格子是正格子；

（4）设晶面族 \((h_1,h_2,h_3)\) 的面间距为 \(d_{h_1h_2h_3}\)，则

\[
d_{h_1h_2h_3}=\frac{2\pi}{|\mathbf k_h|}.\tag{9-4}
\]

有兴趣的同学可以自己证明一下上述性质。

### 9.2.2　X 射线衍射条件

散射势为

\[
V(\mathbf r)=c n(\mathbf r)\tag{9-5}
\]

散射强度

\[
I\propto|u_{\mathbf k,\mathbf k'}|^2\tag{9-6}
\]

其中

\[
u_{\mathbf k,\mathbf k'}\propto\langle\mathbf k'|V(\mathbf r)|\mathbf k\rangle
=c\int e^{i(\mathbf k-\mathbf k')\cdot\mathbf r}n(\mathbf r)\,d\tau\tag{9-7}
\]

对于晶体，在周期性势场中有

\[
n(\mathbf r)=n(\mathbf r+\mathbf R_l)\tag{9-8}
\]

则

\[
n(\mathbf r)=\frac1V\sum_h n(\mathbf K_h)e^{i\mathbf K_h\cdot\mathbf r}\tag{9-9}
\]

\[
\begin{aligned}
u_{\mathbf k,\mathbf k'}&\propto\frac cV\int e^{i(\mathbf k-\mathbf k')\cdot\mathbf r}\sum_h n(\mathbf K_h)e^{i\mathbf K_h\cdot\mathbf r}\,d\tau\\
&=\frac cV\sum_h n(\mathbf K_h)\int e^{i(\mathbf k+\mathbf K_h-\mathbf k')\cdot\mathbf r}\,d\tau\\
&=\frac cV\sum_h n(\mathbf K_h)\delta_{\mathbf k',\,\mathbf k+\mathbf K_h}\\
&=\begin{cases}
cn(\mathbf K_h)/V,&(\mathbf k'=\mathbf k+\mathbf K_h),\\
0,&(\mathbf k'\ne\mathbf k+\mathbf K_h).
\end{cases}
\end{aligned}\tag{9-10}
\]

其中，\(\mathbf k'=\mathbf k+\mathbf K_h\) 就是著名的劳厄方程。

由于动量守恒有

\[
\mathbf k'=\mathbf k+\mathbf K_h\tag{9-11}
\]

对于弹性散射

\[
k^2=k'^2=(\mathbf k+\mathbf K_h)^2\tag{9-12}
\]

\[
k^2+2\mathbf K_h\cdot\mathbf k+K_h^2=k^2
\]

\[
\mathbf K_h\cdot\left(\mathbf k+\frac12\mathbf K_h\right)=0\tag{9-13}
\]

即

\[
\mathbf K_h\perp\left(\mathbf k+\frac12\mathbf K_h\right)\tag{9-14}
\]

将 \(\mathbf K_h=\dfrac{2\pi n}{d}\hat{\mathbf n},\ n=1,2,3,\cdots\) 代入可得

\[
\hat{\mathbf n}\cdot\mathbf k+\frac{n\pi}{d}=0\tag{9-15}
\]

\[
\frac{2\pi}{\lambda}\cos\left(\frac\pi2+\theta\right)+\frac{n\pi}{d}=0\tag{9-16}
\]

\[
2d\sin\theta=n\lambda,\quad n=1,2,3,\cdots\tag{9-17}
\]

这就是布拉格衍射公式。

### 9.2.3　X 光的产生与特性

当具有一定能量的电子和原子碰撞时，可把原子的外层电子撞击到高能态（称为激发）甚至击出原子（称为电离）。当电子从高能态回到低能态，或被电离的原子（离子）与电子复合时，就会发光，这是一般气体放电光源（如生活中常用的日光灯、实验室常用的汞灯、钠灯等）的发光原理。如果电子的能量很高（高达几万电子伏：～\(10^{14}\) J）时，它就可能把原子的内层电子撞击到高能态，甚至击出原子。这时，原子的外层电子就会向内层跃迁，其所发出的光子能量较大，即波长较短，通常称为 X 光。X 光的波长在 0.01～100 Å。X 光也是电磁波。它可穿过不透明的物质。所以它能应用于外科诊断和铸件探伤等。

X 射线产生的专用装置是 X 射线管，如图 9-2 所示，X 射线管被抽成真空，真空管由发射电子的灯丝作阴极和发射 X 射线的金属靶作阳极构成。在 X 射线管的阴阳极之间加上高电压加速电子束轰击金属靶。针对金属靶的 X 光发射方向有一窗口。高速电子接近金属靶原子核时，原子核的库仑场会使它偏转并急剧减速，同时产生电磁辐射，这种辐射称为轫致辐射，它的能量分布是连续的，在光谱图上表现为很宽的 X 光谱带称为连续谱，如图 9-3 中的宽带曲线所示。如果电子的能量再增加时，它就可能把原子的内层电子撞击到高能态，甚至击出原子。这时，原子的外层电子就会向内层跃迁，这时所发射的为 X 特征谱，也称标识谱。

例如，铜原子内主要有两对能级差，分别为 17.4 keV 和 19.6 keV，电子从高能级跃迁到低能级时，分别发出波长为 \(7.11\times10^{-2}\) nm 和 \(6.31\times10^{-2}\) nm 的两种 X 光。这两种 X 光在光谱图上表现为两个尖峰，如图 9-3 所示，在理想情况下为两条线，故称为线光谱，这种线光谱反映了该物质（铜）的特性。也就是说，X 光谱线是由连续谱和特征谱叠加而成。

除了 X 射线管能产生 X 光外，同步回旋加速器中产生的 X 光强度高，单色性好，频率可选择。同时，用 X 射线或 γ 射线激发（XIX）的二次 X 射线也经常被应用。

（1）利用铜的特征 X 射线研究 NaCl 单晶的布拉格反射。

（4）验证 X 射线的波的特征。

## 9.4　实验原理

1913 年，英国科学家布拉格父子（W. H. Bragg 和 W. L. Bragg）认识到在晶体中原子和（或）离子的有序排列可以理解为处于平行晶面上的晶格点组成的阵列。把这样的晶体暴露于平行的 X 射线时，此外假定 X 射线具有波的特性，则晶面上的每一元素都是形成球面波的一个散射点。这些球面波叠加会产生一个反射波前。在这个模型中，波长 \(\lambda\) 相对于入射波前始终是不变的，而且垂直于入射波前和出射波前的辐射方向满足入射角等于反射角的条件。

各个晶面反射的 X 射线在它们的光程差 \(\Delta\) 为波长 \(\lambda\) 的整数倍时，会产生干涉。

\[
\Delta=n\lambda,\quad n=1,2,3,\cdots\tag{9-18}
\]

如图 9-4 所示，对晶面间距为 \(d\) 的相邻两晶面，以掠射角 \(\theta\) 入射和反射的光的光程差为 \(\Delta_1\) 和 \(\Delta_2\)：\(\Delta_1=\Delta_2=d\sin\theta\)。因此总光程差 \(\Delta\) 为

\[
\Delta=2d\sin\theta\tag{9-19}
\]

由式（9-18）和式（9-19）可得布拉格反射定律：

\[
2d\sin\theta=n\lambda\tag{9-20}
\]

本实验中，通过研究 X 射线在 NaCl 单晶上的衍射来证实布拉格反射定律，晶面族平行于晶体原胞的立方体表面。面心立方的 NaCl 单晶的晶面间距 \(d\) 是晶格常数 \(a_0\) 的一半。因此

\[
2d=a_0=562.02\ (\mathrm{pm})\tag{9-21}
\]

实验是利用 X 射线装置内置的测角器进行的。X 射线用 GM 计数管（端窗计数器）检测，它与 NaCl 单晶串联，以相对于入射 X 光二倍耦合的速度旋转；这意味着 GM 计数管总是超前一个角度，它是晶体转角的二倍。如图 9-5 所示。

X 射线实验仪的工作模式有以下三种。

（1）自动扫描模式：在自动扫描模式，按下 SCAN 键后，测角器臂会自动转动。你可以在扫描模式 TARGET、SENSOR 和 COUPLED 间选择。在扫描时，仪器显示当前的计数率与靶的位置，或在耦合扫描模式显示传感器与靶的位置。此外，还一起保存了所有测量数据（角度和计数率）。操作步骤包括：

- 选择扫描模式，按 TARGET、SENSOR 或 COUPLED 键。
- 按 \(\beta\) LIMITS 键，并利用 ADJUST 旋钮设置扫描的下限。
- 按 \(\beta\) LIMITS 键，并利用 ADJUST 旋钮设置扫描的上限。
- 选择测量参数 \(I\) 和 \(U\)。
- 选择角度步长 \(\Delta\beta\)。
- 选择每一个角度想要测量的测量时间 \(\Delta t\)。
- 如果需要，通过 RS-232 串行界面连接计算机，并启动软件程序“X-ray apparatus”。
- 用 SCAN 键启动自动扫描。
- 如果需要，按 REPLAY 键，利用 ADJUST 旋钮可浏览对每个角度储存的测量数据。

（2）手动扫描模式：在手动扫描模式，测量器臂利用 ADJUST 旋钮手动定位。你可以在扫描模式 TARGET、SENSOR 和 COUPLED 间选择。操作步骤包括：

- 选择扫描模式，按 TARGET、SENSOR 或 COUPLED 键。
- 选择测量参数 \(I\) 和 \(U\)。
- 选择每一个角度希望的测量时间 \(\Delta t=1\) s。
- 如果合适，通过 RS-232 串行界面连接计算机，并启动软件程序“X-ray apparatus”。
- 手动调节 ADJUST 旋钮，使测角器臂转到要求的位置。
- 约等 2 s 直至新的角度位置上的计数率在显示板上出现，然后，记下该计数率。

（3）定时曝光模式：如名字所暗示，定时曝光模式对 X 射线胶片让你设置曝光时间，或对单个计数率测量让你设置测量时间。操作步骤包括：

- 安装想要的附件（如测角器或 X 射线胶片夹持架）。
- 需要时，手动调节 ADJUST 旋钮，使测角器的传感器臂或靶臂转到要求的位置。
- 改变测量参数 \(I\) 和 \(U\)。
- 设置角度步长 \(\Delta\beta=0.0°\)。
- 设置想要的测量时间 \(\Delta t\)。
- 用 SCAN 键开始测量：测量时间在显示板上递减至 0。靶臂和传感器臂仍在选定的位置上。
- 测量时间终了时，按下 REPLAY 键。显示板上给出在 \(\Delta t\) 内的平均计数率。

X 射线实验仪在测量中，显示屏可实时地显示 GM 计数管的计数率，它对应接收的 X 光强度。但实验也可以通过实验仪与计算机连接，计算机可实时地与实验仪同步显示 GM 计数管的计数率，并可将实验扫描过程中角度作 X 轴，传感器接受到的 X 光强度即计数率作 Y 轴，实时描绘出掠入射角 \(\theta\) 与计数率 \(R\) 的关系曲线，也可将扫描过程中转动的角度转换成波长作 X 轴，计数率作 Y 轴，实时描绘出波长-\(X\) 光强度关系曲线。

## 9.7　实验内容及步骤

### 9.7.1　实验内容

（1）测量 X 射线通过 NaCl 单晶的布拉格反射，并根据铜靶 X 光谱的特征波长与 NaCl 晶体的晶格常数 \(d\) 的理论值 282.01 pm，计算各级衍射角的理论值，并与实测值相比较，求出其百分误差。

### 9.7.2　X 射线通过 NaCl 单晶的布拉格反射

（1）打开 X 射线实验仪电源。按 ZERO 键，使测角器归零。

（2）启动“X-ray apparatus”软件。按 F4 键清除所有已存的数据。软件设置：X 轴为角度，Y 轴为计数率即 X 射线光强度，表示为 R-1/S。

（3）按住下方的黑色锁定按钮，打开铅玻璃门，把 NaCl 单晶样品放置在样品台上（为防止样品潮解，拿取样品时需戴上手套），调节样品到准直器与传感器的距离分别为 5 cm 和 6 cm 左右。然后，关上铅玻璃门。

（4）设置 X 射线实验参数。

管电压：\(U=35.0\) kV（按 b3 中第一个，旋转 b2 调节）。  
管电流：\(I=1.0\) mA（按 b3 中第二个，旋转 b2 调节）。  
测量时间：每个角度的测量时间 \(\Delta t=5\) s（按 b3 中第三个，旋转 b2 调节）。  
角度步长：\(\Delta\beta=0.1°\)（按 b3 中第四个，旋转 b2 调节）。  
测量的下限角和上限角：下限角为 2.5°，上限角为 25°（按下 COUPLED 键，再按 b3 中第五个，并调节 b2，设置下限角，在重复一次设上限角）。

（5）采用自动扫描模式：按下 COUPLED 键，启动 SCAN 进行自动扫描。放在样品台上的 NaCl 晶体，随测角器转动，从而改变 X 射线的掠入射角 \(\theta\)，传感器（GM 计数器）以 \(2\theta\) 角耦合转动。从晶面族反射的 X 射线进入 GM 计数管进行测量。测量数据被传输到与仪器相连的计算机上，实时地显示出来。

（6）将实验数据与图线保存下来。计算与分析各级衍射角的实验误差和 X 射线 \(K_\alpha\) 和 \(K_\beta\) 的波长。

根据铜靶 X 光谱的特征波长 7.11×10⁻² nm 和 6.31×10⁻² nm，与 NaCl 晶体晶格常数 \(d\) 的理论值 282.01 pm，可计算各级衍射角的理论值，并与实测值比较，求出其百分误差。

### 9.7.3　测量 X 射线通过 LiF 单晶的布拉格衍射曲线

在以上实验完成的基础上，将样品换成 LiF 单晶。实验参数设置基本与以上实验相同（上限角扩展到 35°）。就可测绘出 X 射线通过 LiF 单晶的布拉格衍射曲线，根据测出的各级衍射角，计算 LiF 晶体的晶格常数 \(d\)，与其理论值 \(d=201\) pm 比较，求出其百分误差。

## 9.8　实验注意事项

（1）NaCl 晶体会吸湿，易碎。应把它储存在干燥的地方。应避免在晶体上施加压力，只触摸其窄的侧面。

（2）如计数率太低，可稍许减小靶与传感器之间的距离 \(s_2\)。这个距离不应该太小，否则测角器的角分辨率不再足够达到能分离特征 \(K_\alpha\) 和 \(K_\beta\) 线。

（3）实验前应检查样品表面是否平整。

（4）须注意高压安全。

（5）对于新的 X 射线管和超过 100 h 未使用的 X 光管，需进行正常老化；对于超过 24 h 但不超过 100 h 未使用的 X 射线管，需进行快速老化。

（6）X 射线会对人体组织造成伤害。因此要时刻注意铅玻璃等防护材料是否完整，不用的窗口关闭好，如存在防护材料不完整，需立即停止实验，并进行修复。

（7）不得随意加大 X 射线管的工作电压和工作电流，以免过载。

## 9.10　拓展实验设计参考

### 测量薄膜厚度

当 X 射线照到晶体材料（如银等）单层膜时，一方面由于晶体具有点阵结构，当晶面满足布拉格条件时会发生衍射。一般材料的晶面间距 \(d\) 是零点几纳米，所以由材料本身的晶面反射所产生的衍射峰大多出现在大角范围内（衍射角 \(\theta>5°\)）。另一方面，X 射线通过单层膜，会发生单缝衍射效应。薄膜的厚度 \(D\) 相当于单缝衍射的峰宽。当单层膜的厚度在几十纳米时，由此产生的衍射峰一般出现在小角区域（衍射角 \(\theta<5°\)）。从而可以通过测定该衍射峰的峰位来计算单层膜的膜厚。

![图 9-12 衍射原理（薄膜厚度 D、入射和出射角 θ、光程差 λ）](../../近代物理实验教材.pdf#page=113)

**图 9-12　衍射原理**

由单峰衍射（图 9-12）所产生衍射峰的峰位满足

\[
2D\sin\theta=n\lambda\tag{9-22}
\]

其中，\(D\) 是单层膜的膜厚，\(n\) 表示衍射级数，\(\theta\) 为衍射峰的峰位，\(\lambda\) 为 X 射线波长。对于两个相等的衍射峰，如第 \(n\) 级和第 \(n+1\) 级，于是有

\[
2D\sin\theta_{n+1}=(n+1)\lambda\tag{9-23}
\]

\[
2D\sin\theta_n=n\lambda\tag{9-24}
\]

由式（9-23）与式（9-24）相减可得

\[
2D(\sin\theta_{n+1}-\sin\theta_n)=\lambda\tag{9-25}
\]

从而膜厚为

\[
D=\frac{\lambda}{2(\sin\theta_{n+1}-\sin\theta_n)}\tag{9-26}
\]

因此可以通过测量单层膜的衍射谱，得到相邻两个衍射峰的峰位，从而计算出薄膜的厚度 \(D\)。
